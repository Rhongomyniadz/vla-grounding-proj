# 第 1 周：环境与从感知到动作的流水线

[English](week-01.en.md) | [简体中文](week-01.zh-CN.md)

[每周计划索引](README.zh-CN.md) | [实施计划](../doc/IMPLEMENTATION_PLAN.zh-CN.md)

**目标:** 验证 RTX 5080/WSL2 运行环境，并解释机器人观测到什么、策略预测什么。

**开始条件:** 已有项目规划文档，并且能够访问另一台 RTX 5080 电脑；不假设项目运行环境已经搭建。

时间预算：五次学习共十二小时主动投入，其中一小时关闭智能体独立完成；电脑运行时间另计。

## 准备与学习

- 阅读实施计划中的环境和感知到动作接口部分，再检查固定版本 LeRobot 的安装及 LIBERO 接口。
- 学习观测、本体感知、末端执行器位姿、夹爪指令、相对控制、动作块和模型检查点。
- 画出两路相机图像、机器人状态和指令到实际动作的路径，标出预处理与动作解码。

## 分次任务

### 1. 确认目标电脑并预测数据流 (2 小时)

- [ ] 你：记录目标 GPU、可用内存与存储、Windows/WSL/Ubuntu 版本，以及 Linux 项目文件的存放位置。
- [ ] 你：先独立画出观测到动作的草图，再请智能体讲解；标出尚不能解释的概念。
- [ ] 智能体：检查固定版本的上游安装要求，提出仅运行仿真所需的最小环境配置。

### 2. 搭建并验证基础环境 (3 小时)

- [ ] 智能体：按约定版本和受支持接口，实现可复现依赖安装、CUDA 检查及无界面渲染检查。
- [ ] 你：在 WSL 中执行检查，查看两路相机画面，确认报告的设备是目标 RTX 5080。
- [ ] 发生错误时保存原始命令和报错，定位失败层次，验证针对根本原因的修复后再继续。

### 3. 加载检查点并检查真实预测 (3 小时)

- [ ] 智能体：通过小型连接层提供检查点加载和观测预处理，不替你实现完整回合外层循环。
- [ ] 你：检查原始及处理后的图像/状态形状、分词结果与掩码、特征映射、归一化器、预测动作块及执行动作维度。
- [ ] 使用已有上游冒烟检查或评估接口获得预测、执行仿真步进并保存可播放短视频，记录解析后的资源版本。

### 4. 独立工作后再复核 (2 小时)

- [ ] 前一小时关闭智能体，编写小型检查函数，输出真实观测的形状、数据类型、取值范围和有限数值检查。
- [ ] 结合检查结果说明哪些表示在预处理中发生变化，以及哪些量描述机器人而不是场景。
- [ ] 后一小时请智能体审查你的解释和辅助函数，修正一个误解并重新执行对应检查。

### 5. 整理证据并准备下一项任务 (2 小时)

- [ ] 保存环境检查输出、两路相机示例、解析后版本、检查点标识和冒烟视频，作为开发产物。
- [ ] 只记录已经验证可用的命令；未解决的兼容性问题应明确保留，不编造完整快速开始说明。
- [ ] 准备第 2 周的明确请求：提供连接层和视频支持，把回合循环保留给自己实现。

## 证据与完成检查

- [ ] 已验证 CUDA 运算、两路相机渲染、检查点加载、有限数值预测、仿真步进和视频播放。
- [ ] 能够在已保存示例中指出真实图像、状态、语言、动作块和执行动作的表示。
- [ ] 能够找回环境配置和不可变资源引用；故障已经解决，或被明确记录为未解决。

## 关闭智能体后解释

1. 机器人状态与相机观测分别提供什么信息？
2. 指令在哪一步进入流水线，哪些预处理可能意外删除重要词语？
3. 一个动作控制什么，为什么预测有效还不能证明任务成功？

## 给编程智能体的建议请求

> 实现环境检查器和最小 LeRobot 连接层，解释输入输出，并将完整单回合循环留给我。

## 进入下一周的条件

当环境能够预测并执行真实策略动作、保存观测后，再进入第 2 周。应先解决环境故障，再调试任务行为。
