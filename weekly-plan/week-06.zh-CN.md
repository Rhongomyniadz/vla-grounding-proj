# 第 6 周：指标、不确定性与开发基线

[English](week-06.en.md) | [简体中文](week-06.zh-CN.md)

[每周计划索引](README.zh-CN.md) | [实施计划](../doc/IMPLEMENTATION_PLAN.zh-CN.md)

**目标:** 亲自实现核心指标，并解释开发结果能够和不能支持什么结论。

**开始条件:** 第 5 周已提供有效语言用例和经过验证的请求目标评分，最终留出用例尚未使用。

时间预算：五次学习共十二小时主动投入，其中一小时关闭智能体独立完成；电脑运行时间另计。

## 准备与学习

- 阅读实施计划中的指标定义，区分配对结果与独立成功率比较。
- 理解百分点差异、任务等权重、以选定任务为条件的不确定性，以及 bootstrap 重采样单位。
- 选择汇总逻辑前，检查包含超时、同时完成多个目标和基础设施错误的真实回合记录。

## 分次任务

### 1. 手工计算一个真实示例 (2 小时)

- [ ] 你：选取已完成的小型开发实验，手工统计成功、首个物体选择、配对正确性和每个任务的完成覆盖。
- [ ] 计算标准指令成功率及一个开发改写的差值，解释分母和正负号。
- [ ] 执行异常视为未完成工作，不把部分完成实验当作完整基准结果。

### 2. 实现核心指标函数 (3 小时)

- [ ] 你：编写纯函数，计算各条件成功率、改写差距、首个物体选择、配对正确率和策略间差异。
- [ ] 用已保存真实记录核对手算结果，按评分器约定一致处理同时完成多个目标的情况。
- [ ] 智能体：审查类型、分组、缺失用例报错和任务等权重，不替代你的首次实现。

### 3. 增加不确定性估计和有效图表 (3 小时)

- [ ] 在智能体指导下，按计划实现 2,000 次分组 bootstrap 重采样，保留每个初始状态内条件间的配对关系。
- [ ] 智能体：使用你的指标函数生成图表和导出结果，明确标为开发结果，并标注任务样本量、覆盖率及区间定义。
- [ ] 这些检查仅使用训练/验证措辞和开发状态，不用最终留出模板或状态调试分析。

### 4. 独立审查一个指标后再复核 (2 小时)

- [ ] 前一小时关闭智能体，把一个图中数值从真实原始回合记录、分组一直追踪到最终计算。
- [ ] 解释若对同一初始状态下的改写结果独立重采样，会改变什么。
- [ ] 后一小时请智能体质疑计算和不确定性解读，必要时修正实现。

### 5. 编写暂定解读 (2 小时)

- [ ] 你：先独立描述开发发现、不确定性和替代解释，再请智能体批评。
- [ ] 区分有关操作技能、语言改写不变性、目标选择和空指令行为的证据。
- [ ] 固定分析定义和最终预期输出，防止根据后续检查点表现重新定义主指标。

## 证据与完成检查

- [ ] 自己实现的指标与真实开发记录的手工计算一致。
- [ ] Bootstrap 分组保留配对关系及任务权重，图表披露样本量和不完整覆盖。
- [ ] 暂定结论明确标为开发结果，最终留出用例仍未使用。

## 关闭智能体后解释

1. 为什么同一初始状态上的两个条件在 bootstrap 时应保持配对？
2. 改写差距为负意味着什么，又不能解释什么？
3. 为何这里的不确定性不能衡量所有任务或所有训练种子上的泛化？

## 给编程智能体的建议请求

> 用真实记录审查我的指标函数，协助分组 bootstrap 和绘图，并在润色前质疑我的解读。

## 进入下一周的条件

所有开发结果都能追溯到记录，且不用智能体也能解释重采样单位后，再进入下一周。
