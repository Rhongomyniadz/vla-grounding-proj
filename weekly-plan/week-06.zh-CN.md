## 执行位置

使用[统一交接步骤](../doc/ENVIRONMENT.zh-CN.md#每次访问运行电脑时的交接)，下方每次学习的位置约束详细操作。

1. **在编码电脑准备：** 实现指标、分组 bootstrap 和绘图流水线，使用已声明可迁移依赖；真实记录存在前不报告数值。
2. **在运行电脑执行：** 使用第 5 周已验证开发记录；数值验证前，在运行电脑补齐任何缺失开发覆盖。
3. **带回审查：** 带回分母及配对需要的全部清单/结果行，包括未完成运行日志和首物体并列。在此手工核对并生成开发图表。

无法访问目标时，保留真实运行检查待完成，记录具体访问或安装阻碍，准备准确交接并继续不依赖目标证据的开发。

理解目标：

- 用少量真实记录推导成功率、改写差距和干预收益的分母及正负号。
- 解释任务等权、严格首先选择与最终成功的区别，以及显式并列处理。
- 解释 bootstrap 为何保留初始状态内全部条件/策略，区间为何不覆盖新任务或训练种子。

## 准备与学习

- 阅读实施计划中的指标定义，区分配对结果与独立成功率比较。
- 理解百分点差异、任务等权重、以选定任务为条件的不确定性，以及 bootstrap 重采样单位。
- 选择汇总逻辑前，检查包含超时、同时完成多个目标和基础设施错误的真实回合记录。

## 实现任务

以下条目明确本周代码及文档交付。现有源码按需完善或扩展；未来组件在真正实现前保持计划状态。实验参数仍以链接的实施计划为准。

1. **校验结果读取与覆盖。** 将保存的开发清单/结果读取为强类型记录，不导入仿真器。完整面板统计前拒绝重复 ID、缺失必需配对、混合后端标识及未解释缺失覆盖，区分超时失败和基础设施执行未完成。
2. **核心纯函数指标。** 按权威定义实现任务/条件/策略成功率、改写差距、改变目标成功、首物体选择、严格配对正确率及策略/干预差异。返回新汇总，不修改输入行；保留同时首目标并列，不任意指定物体。
3. **算术核对与任务权重。** 独立于汇总实现，对少量真实记录计算分子、分母、配对成员及差值正负号，核对函数结果。采用任务等权，不因完成数量不均而改变预定统计量。
4. **分组不确定性。** 在每个任务内按初始状态组可复现地 bootstrap，关联的全部语言条件和策略结果一起重采样。区间/重采样规格引用实施计划，每份汇总保存种子、分组单位、指标标识和任务权重。
5. **图表与导出。** 直接从校验汇总生成图表及机器可读表，标注样本数、覆盖、区间定义和仅开发标签。相对复制回来的运行根目录解析产物，使 Windows 使用已声明依赖即可分析；缺少微调策略结果时不报告其数值。
6. **分析命令与文档。** 提供明确清单/结果/输出输入，使用返回真实记录运行分析，并将一个图中值追踪到原始行。在现有双语文档说明公式、配对/并列处理、bootstrap 控制流、错误条件和含替代解释的暂定解读。

## 分次任务

### 1. 手工计算一个真实示例 (2 小时)

**位置：** 编码电脑：从返回的第 5 周真实记录手工计算；不可用时延后本次证据。

**详细操作步骤**

1. 选小型完整开发子集，手工列表记录任务、状态、条件、结果、首个物体和配对标识。

2. 计算成功率前先统计计划与完成用例，区分任务失败、超时及未完成基础设施执行。

3. 对该完整子集按条件用成功数除以有效已完成数，先算各任务，再按任务等权汇总。

4. 逐配对状态比较标准与改写结果，另行检查原始/改变目标首个物体是否正确，写明各差值方向。

**应得到的结果:** 能解释首个真实指标输出的手算表。

**如果没有达到预期:** 不能从记录重建分母时，先修复缺失/重复标识，再写绘图函数。

**本次完成清单**

- [ ] 选取已完成的小型开发实验，手工统计成功、首个物体选择、配对正确性和每个任务的完成覆盖。
- [ ] 计算标准指令成功率及一个开发改写的差值，解释分母和正负号。
- [ ] 执行异常视为未完成工作，不把部分完成实验当作完整基准结果。

### 2. 实现核心指标函数 (3 小时)

**位置：** 编码电脑：编写纯指标，真实手工表可用后再核对。

**详细操作步骤**

1. 编写接收明确记录的纯汇总函数，返回计算结果，不修改原记录。

2. 实现约定关系：改写差距为改写减标准成功率，干预增益比较匹配用例上的改写组与对照组。

3. 配对正确要求两回合首个物体均符合请求，并列情况明确保留，不能用最终成功替代严格首次选择。

4. 用手算表核对输出，缺配对、重复结果和混合后端必须明确报错，不能悄悄改分母。

**应得到的结果:** 正确指标函数，以及能够逐行解释的真实记录核对。

**如果没有达到预期:** 若总体均值只因某任务完成回合更多而变化，应检查任务权重与覆盖。

**本次完成清单**

- [ ] 编写纯函数，计算各条件成功率、改写差距、首个物体选择、配对正确率和策略间差异。
- [ ] 用已保存真实记录核对手算结果，按评分器约定一致处理同时完成多个目标的情况。
- [ ] 审查类型、分组、缺失用例报错和任务等权重，实现并验证完整指标流水线。

### 3. 增加不确定性估计和有效图表 (3 小时)

**位置：** 编码电脑：使用已声明分析依赖及返回的完整开发记录，实现并运行 bootstrap/图表。

**详细操作步骤**

1. 按任务和初始状态分组真实开发记录，同状态下所有语言条件和对比策略结果必须保留在一组。

2. 各任务内对状态组有放回 bootstrap 重采样，重算相同配对统计量，采用计划次数。

3. 由重采样分布取得区间，记录种子、采样单位、任务权重和指标定义。

4. 用这些汇总画图，显示样本量和开发标签；空指令仍沿用声明的原目标评分。

**应得到的结果:** 采样单位明确、图表能追溯相同真实记录的不确定性计算。

**如果没有达到预期:** 独立重采样单条改写会破坏共享状态依赖，不是约定的配对流程。

**本次完成清单**

- [ ] 按计划实现 2,000 次分组 bootstrap 重采样，保留每个初始状态内条件间的配对关系。
- [ ] 使用你的指标函数生成图表和导出结果，明确标为开发结果，并标注任务样本量、覆盖率及区间定义。
- [ ] 这些检查仅使用训练/验证措辞和开发状态，不用最终留出模板或状态调试分析。

### 4. 审查一个指标并记录结论 (2 小时)

**位置：** 编码电脑：独立审查真实记录、分组和绘图算术；只有底层证据缺失或无效时才需要目标执行。

**详细操作步骤**

1. 选择一个图中率值和一个配对差值，找出所有底层记录并复算。

2. 概念上追踪一次 bootstrap 抽样，指出重复的状态组及必须同行的条件。

3. 解释区间为何以选定任务和训练权重为条件，不能代表所有任务或新训练种子。

4. 审查证据及最强替代解释，修正已定位根因，重跑受影响检查，在对应 `doc/` 双语文档中记录理由。

**应得到的结果:** 不用生成推理也能为一个结果和不确定性提供依据。

**如果没有达到预期:** 窄区间无法弥补错误评分器或有偏任务选择。

**本次完成清单**

- [ ] 把一个图中数值从真实原始回合记录、分组一直追踪到最终计算。
- [ ] 解释若对同一初始状态下的改写结果独立重采样，会改变什么。
- [ ] 核实推理及修正，重跑受影响检查，更新双语设计/代码说明及证据引用。

### 5. 编写暂定解读 (2 小时)

**位置：** 编码电脑：基于真实记录检查后，撰写开发解读并固定指标定义。

**详细操作步骤**

1. 在对应的 `doc/` 双语文档撰写简短且明确为开发结果的发现，附表格、区间及至少一种竞争解释。

2. 区分语言改写不变性、目标改变响应、操作能力和无指令行为。

3. 在看到最终微调结果前，固定指标定义、汇总规则和预期图表标签。

4. 列出两个训练策略出现后可新增的比较输出，不编造当前不存在的数值。

**应得到的结果:** 谨慎的暂定解读，以及后续结果的固定分析约定。

**如果没有达到预期:** 不能只因另一个探索数值更好看就修改主指标。

**本次完成清单**

- [ ] 记录开发发现、不确定性及替代解释，再逐项检查证据。
- [ ] 区分有关操作技能、语言改写不变性、目标选择和空指令行为的证据。
- [ ] 固定分析定义和最终预期输出，防止根据后续检查点表现重新定义主指标。
