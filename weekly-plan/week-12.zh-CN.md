# 第 12 周：复现、展示与独立理解验证

[English](week-12.en.md) | [简体中文](week-12.zh-CN.md)

[每周计划索引](README.zh-CN.md) | [实施计划](../doc/IMPLEMENTATION_PLAN.zh-CN.md)

**目标:** 完成可审阅作品集，并证明自己能够操作和修改核心系统。

**开始条件:** 第 11 周已具备有证据支持的报告、最终图表、带注释案例和保留的实验产物。

时间预算：五次学习共十二小时主动投入，其中一小时关闭智能体独立完成；电脑运行时间另计。

## 准备与学习

- 以新贡献者视角阅读安装/运行说明，找出只存在于个人终端或记忆中的假设。
- 复核实施计划中的全部学习验收要求，选择有代表性的小型复现面板。
- 区分复现配置与测量行为，以及承诺跨不同运行环境得到逐位一致 GPU 结果。

## 分次任务

### 1. 准备全新复现环境 (2 小时)

- [ ] 智能体：新建项目环境，不删除当前可用环境、数据集、检查点或最终产物。
- [ ] 使用锁定依赖及不可变源/资源引用，再次验证 CUDA、两路相机、策略输入和处理流水线标识。
- [ ] 你：严格按文档执行，找出缺失的环境变量、路径、资源或未说明手动步骤。

### 2. 复现有代表性的对照 (3 小时)

- [ ] 为三个策略分别运行包含一对原始/改变目标回合和一个鲁棒性用例的小型明确面板。
- [ ] 与保留记录比较恢复状态/变体标识、实际指令、预测/执行动作、评分、元数据和结果。
- [ ] 结合已记录数值容差及运行细节排查差异，说明剩余可复现性局限，不宣称重跑了全套实验。

### 3. 完成作品集讲解 (3 小时)

- [ ] 你：准备简短讲解，覆盖研究问题、系统数据流、对照设计、主要发现和局限。
- [ ] 智能体：协助将已有图表、带注释视频、产物链接和验证过的安装/运行命令整理进 README 和报告。
- [ ] 核实所有展示结果真实且有标签，生成产物可找回，不自动发布或提交。

### 4. 独立修改核心后再复核 (2 小时)

- [ ] 前一小时关闭智能体，添加一个有用分析指标，或对回合/用例逻辑进行仅用于开发的受控修改。
- [ ] 先预测效果，再实现并用真实保存记录或开发回合验证，不改变冻结的最终条件。
- [ ] 后一小时向智能体解释修改及证据，审查正确性，若影响架构则同步检查中英文文档。

### 5. 完成学习与仓库最终审查 (2 小时)

- [ ] 关闭智能体，梳理完整指令到动作回合，解释配对目标评分及微调对照，并诊断一个已保存失败。
- [ ] 检查文档链接、双语对应、每周清单状态、复现证据和报告一致性，未完成项保持明确未勾选。
- [ ] 将有依据的下一项实验记录为未来工作，同时保留当前项目范围、证据和未提交审阅状态。

## 证据与完成检查

- [ ] 全新环境能执行文档中的代表性对照，并解释复现差异。
- [ ] 作品集链接到已验证安装、真实结果、不确定性、注释案例和明确局限。
- [ ] 能够独立修改并验证核心组件，不用智能体也能解释系统、实验、指标和结论。

## 关闭智能体后解释

1. 现在项目中哪些部分，你已经能不依赖生成代码而自行实现或诊断？
2. 什么证据会改变你的主要结论，你会如何设计下一项实验？
3. 其他人能否只凭仓库和引用产物复现一项选定对照？

## 给编程智能体的建议请求

> 协助在全新环境中复现项目，核对产物/文档一致性，审查我的独立核心代码练习，不接管首次尝试。

## 进入下一周的条件

软件与独立学习验收均通过时项目才算完成。未达标项保持未完成，可复现的负面微调结果仍是有效成果。
