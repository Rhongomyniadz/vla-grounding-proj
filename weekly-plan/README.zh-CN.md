# 每周学习与实施计划

[English](README.en.md) | [简体中文](README.zh-CN.md)

本目录将[实施计划](../doc/IMPLEMENTATION_PLAN.zh-CN.md)拆分为十二周的具体学习与执行任务。内容表示计划工作，不代表代码或实验已经完成。所有任务复选框初始均未勾选。

## 使用方式

1. 请智能体编码前，先阅读本周目标、前置条件和概念准备。
2. 每周分五次完成：2 + 3 + 3 + 2 + 2 = 12 小时主动投入。约定每周十到十五小时内的剩余时间可用于诊断或深入理解。
3. 第四次学习的前一小时关闭智能体，亲自完成指定练习；后一小时用于复核。
4. 学习者负责的逻辑先自己尝试；委托工作使用文件中的具体智能体请求，并明确预期证据。
5. 检查证据后再勾选完成状态。中英文版本的完成状态和实质性修改应同步。
6. 不用智能体回答理解检查问题，满足交接条件后再开展依赖本周成果的工作。

时间预算包含阅读、编码、小型检查和复核，不预测无人值守 GPU 运行时长。训练与评估按实测吞吐量安排；前置任务超过日历周时顺延，不跳过验证或悄悄缩减实验。

## 各类信息的权威来源

- 架构、评估定义、任务选择、训练参数和验收条件：[英文实施计划](../doc/IMPLEMENTATION_PLAN.en.md) / [中文实施计划](../doc/IMPLEMENTATION_PLAN.zh-CN.md)。
- 分次任务和独立练习：下列每周双语文件。
- 当前实现细节：实现后的源码和文档字符串。
- 观察与概念探索：创建后的现有项目笔记本。
- 实验证据：实际生成的清单、结果、轨迹和视频。

架构文档放在 `doc/`，每周任务清单放在 `weekly-plan/`。周计划引用规格，不另建重复架构说明。如果实现改变已约定设计，应同时更新架构文档的中英文版本及对应周计划。

## 学习与实验边界

- 环境和库接口集成可以委托；回合循环、用例构建、目标选择和基本指标保留给你首次实现。
- 开发与调试使用开发初始状态和允许的训练/验证措辞，最终状态及最终测试模板不参与调参。
- 最终评估前固定检查点选择，开发、选择、最终和复现运行均明确标记。
- 保留异常与缺失覆盖，不编造结果、不悄悄改变控制条件，也不将部分运行宣称为研究完成。
- 学习内容使用同一个当前项目笔记本，不每周新建叙事日记。
- 本周期不增加仪表盘、其他模型家族、实体硬件、强化学习或自动发布。
- 除非你明确要求提交，否则改动保持未提交状态。

## 完成要求

软件和独立学习验收都通过后，项目才算完成。可复现的负面微调结果是有效成果；原因不明或未完成的流水线不能作为这种结果的证据。
