# 第 10 周：选择检查点并执行冻结的最终研究

[English](week-10.en.md) | [简体中文](week-10.zh-CN.md)

[每周计划索引](README.zh-CN.md) | [实施计划](../doc/IMPLEMENTATION_PLAN.zh-CN.md)

**文档：** 同步更新[双语代码指南](../doc/CODE_GUIDE.zh-CN.md)，覆盖本周设计理由、已实现结构及验证证据。

**目标:** 按预先声明规则选模型，然后完成最终评估，不根据测试结果调参。

**开始开发:** 已有选择、清单和覆盖约定；现在可编写逻辑，真实检查点标识在训练证据返回后绑定。

**运行电脑前置条件:** 两组完整训练均已完成且可重载，最终语言状态/模板和鲁棒性清单保持冻结，没有用于调参。

工作估算：五次任务共十二小时主动工作，包含证据审查及文档。GPU 运行时间另计并按实测安排。

## 执行位置

使用[统一交接步骤](../doc/ENVIRONMENT.zh-CN.md#每次访问运行电脑时的交接)，下方每次学习的位置约束详细操作。

1. **在编码电脑准备：** 准备固定选择规则实现、候选/清单审查和覆盖检查器。验证选择冻结前，最终结果保持不可用。
2. **在运行电脑执行：** 两组训练通过后，评估全部验证候选，固定选择及准确源码/配置，再执行/恢复完整最终面板。
3. **带回审查：** 带回候选分数及选中检查点标识、不可变最终清单、全部最终结果行、源码/后端标识、覆盖/错误/恢复记录及审查所需产物。

无法访问目标时，保留真实运行检查待完成，记录具体访问或安装阻碍，准备准确交接并继续不依赖目标证据的开发。

## 阅读内容与理解目标

按以下顺序阅读。尚不存在的源码会明确标注；完成本里程碑前，将计划代码描述替换为实际文件/符号链接，并补充对应证据引用。

理解目标：

- 按验证状态/措辞推导选择，解释最终结果和训练损失不能替代既定规则。
- 按清单标识重建每策略 480 语言 + 160 鲁棒性/参考、共 1,920 回合。
- 区分操作重试与条件变化，解释真实评分/执行错误后受影响比较的统一重跑。

- 安排长时间评估前，检查所有用例配对键和完成覆盖汇总。

## 实现任务

以下条目明确本周代码及文档交付。现有源码按需完善或扩展；未来组件在真正实现前保持计划状态。实验参数仍以链接的实施计划为准。

1. **候选与验证清单准备。** 按优化器步枚举实际检查点，校验基础/处理器标识，构建约定开发状态/标准指令/验证改写面板。拒绝缺失或无法加载候选，保留每个候选逐用例结果。
2. **确定性检查点选择。** 用明确函数实现事先约定分数汇总及优先较早检查点的并列规则，保存完整候选得分表和两组选定不可变标识。训练损失偏好及最终测试结果不参与选择。
3. **最终用例与策略冻结。** 将基线及选定适配器/处理器绑定到冻结语言/鲁棒性/参考用例。校验任务/状态/模板划分、准确指令、请求目标、采样种子、后端、上限及动作执行步数；启动前拒绝重复 ID、缺配对及可变资源/模型引用。
4. **最终执行与恢复。** 用已验证清单执行器运行全部策略/后端任务，明确输出、轨迹/视频、结构化进度及资源监测。不改变条件、不将基础设施错误计为完成失败，恢复兼容未完成工作。
5. **覆盖与正确性审查。** 按策略、任务、条件和后端比较预期/实际回合 ID，同时检查意外记录。跨策略检查一对真实原始/改变目标及一个鲁棒性用例。真实执行/评分错误发生时定位无效范围，用统一标识修正重跑全部受影响比较。
6. **冻结结果集与文档。** 保留完整最终记录、选择证据、清单、源码/后端标识及修正/恢复来源。导出覆盖报告及可迁移分析链接，说明选择函数、冻结校验、恢复边界和完整性规则；缺口明确报告，不宣称计划研究已完成。

## 分次任务

### 1. 使用开发验证选择检查点 (2 小时)

**位置：** 编码电脑：实现并审查选择规则。运行电脑：加载/评估真实候选；从返回验证分数计算选择。

**详细操作步骤**

1. 按真实保存的优化步骤列出两组候选，验证每个都能用预期处理器和基础版本加载。

2. 由开发状态、标准指令和唯一验证模板生成验证面板，启动前核对数量。

3. 为每候选计算约定等权得分并保留分任务结果，取最高者，完全并列时取较早步骤。

4. 记录选中标识及支持表，在产生最终结果前结束模型选择，不用视频偏好或训练损失替换规则。

**应得到的结果:** 可复现选择表和两个冻结选中检查点。

**如果没有达到预期:** 缺失或无效候选属于训练/检查点问题，不能悄悄更换候选集合。

**本次完成清单**

- [ ] 每组五个候选检查点分别在四任务、五开发状态、标准指令和仅验证改写上评估。
- [ ] 使用预先规定的平均成功率规则，并列时选更早检查点，保存全部验证得分和选中标识。
- [ ] 计算并记录一个小型选择示例，确认训练损失和最终测试表现没有取代既定规则。

### 2. 固定最终策略及用例标识 (3 小时)

**位置：** 编码电脑：审查预期用例。运行电脑：绑定真实检查点/资源/状态路径，确认资源并固定最终运行标识。

**详细操作步骤**

1. 列出最终基线及选中策略/适配器权重、处理器、分词器、代码/资源、后端和配置标识。

2. 按规格审查任务、初始状态、实际文本、请求目标、采样种子、上限、相机/控制和执行步数。

3. 执行前检查唯一性和配对完整性，避免开发用例或验证措辞误标最终。

4. 按实测吞吐量分别估计模型选择与最终运行，确认存储和资源余量后冻结清单。

**应得到的结果:** 不依赖变化本地默认值的完整最终运行目录。

**如果没有达到预期:** 若命令在运行时解析可变模型/数据引用，应先固定再收集结果。

**本次完成清单**

- [ ] 记录预训练策略、两个选中适配器、处理流水线、后端和评估配置的不可变标识。
- [ ] 按计划审查最终语言矩阵、鲁棒性用例、种子、初始状态、指令划分、时间上限和动作执行步数。
- [ ] 生成完整用例数量/覆盖预期，并根据真实试验吞吐量估算包括前面模型选择在内的实际运行成本。

### 3. 运行最终语言和鲁棒性面板 (3 小时)

**位置：** 运行电脑：执行并恢复冻结的最终语言/鲁棒性面板，不改变源码或条件。

**详细操作步骤**

1. 用验证过执行器启动固定清单，记录正在执行的策略/后端任务，所有运行设置保留冻结配置。

2. 监测完成数、异常、磁盘和进程健康，成功率低不是改条件的理由。

3. 中断后先核对清单标识及已完成 ID，再恢复未完成用例；部分产物仅作诊断，不算完成。

4. 开发、选择和最终输出分离，避免汇总重复计数或混合调参和测试数据。

**应得到的结果:** 进度可审查、科学条件未变化的最终执行。

**如果没有达到预期:** 真实实现错误影响评分或动作时暂停相关比较，识别无效范围，明确修正后统一重跑。

**本次完成清单**

- [ ] 为三个策略执行冻结清单，保存视频、轨迹、完整元数据并显示进度。
- [ ] 监测运行健康和完成覆盖，不根据逐渐出现的成功率修改指令、任务、检查点或设置。
- [ ] 中断后只按原清单恢复，不把基础设施异常算作完成的失败，也不悄悄丢掉困难用例。

### 4. 审查证据并记录结论 (2 小时)

**位置：** 编码电脑：审查返回配对结果/视频。修正错误须以明确修正快照在目标统一重跑受影响比较。

**详细操作步骤**

1. 选择跨策略的原始/改变目标最终对照及一个鲁棒性用例。

2. 比较实际输入文本、初始状态/变体、策略种子、权重/处理器、首个目标、结束原因和视频。

3. 将差异追溯到原产物，判定仅报告错误还是底层执行无效。

4. 审查证据及最强替代解释，修正已定位根因，重跑受影响检查，在对应 `doc/` 双语文档中记录理由。

**应得到的结果:** 独立最终记录审查，以及修正范围的合理依据。

**如果没有达到预期:** 不删除不利用例、不只保留成功重跑，也不能只改一个策略而让其他可比结果仍无效。

**本次完成清单**

- [ ] 从记录和视频审查跨策略的一对原始/改变目标用例及一个鲁棒性用例。
- [ ] 核实实际请求文本、目标评分器、初始状态/变体、采样种子、策略标识和终止行为。
- [ ] 核实推理及修正，重跑受影响检查，更新双语设计/代码说明及证据引用。

### 5. 核对完成覆盖并保留最终数据 (2 小时)

**位置：** 编码电脑：按清单核对全部返回最终 ID。运行电脑：完成缺失有效用例并保留全量原始证据。

**详细操作步骤**

1. 按策略、任务、条件和后端核对预期与实际 ID，同时查缺失及额外记录。

2. 验证源计划语言及鲁棒性完整总量，超时算完成失败，基础设施异常算未完成。

3. 汇总只读取已完成且正确的最终集合，保留修正和恢复来源。

4. 固定证据集，明确未解决缺口；部分数据可以支持有明确局限的报告，不能宣称计划研究已完成。

**应得到的结果:** 覆盖已验证、没有隐藏缺失的待分析结果集。

**如果没有达到预期:** 总文件数不足以证明完整，重复 ID 可能掩盖缺失，应比较身份集合。

**本次完成清单**

- [ ] 确认每个策略完成 480 个语言用例和 160 个鲁棒性/参考用例，共计 1,920 个最终回合。
- [ ] 开发和模型选择运行保持独立标签，保留异常及重跑来源，不隐藏这些记录。
- [ ] 固定完整结果供第 11 周分析；未解决缺失必须明确记录，不能宣称全部完成。
