# 第 2 周：编写并理解一个完整机器人回合

[English](week-02.en.md) | [简体中文](week-02.zh-CN.md)

[每周计划索引](README.zh-CN.md) | [实施计划](../doc/IMPLEMENTATION_PLAN.zh-CN.md)

**目标:** 亲自实现首个推理外层循环，并梳理一次完整仿真回合。

**开始条件:** 第 1 周检查通过，检查点与处理流水线可加载，仿真器和策略连接层已可使用。

时间预算：五次学习共十二小时主动投入，其中一小时关闭智能体独立完成；电脑运行时间另计。

## 准备与学习

- 检查固定版本策略的重置与动作选择方法，以及仿真器的重置、步进、成功和终止行为。
- 理解归一化模型动作、解码后的控制动作与控制器坐标约定之间的区别。
- 阅读动作队列实现，确认何时生成新动作块、何时复用已有动作。

## 分次任务

### 1. 编码前先明确单回合流程 (2 小时)

- [ ] 你：编写伪代码，覆盖环境重置、策略重置、观测准备、指令传入、动作选择、步进、评分和资源关闭。
- [ ] 检查真实步进返回值，区分任务成功、回合终止、超时与执行异常。
- [ ] 智能体：审查伪代码及连接层约定，但不直接给出完整循环。

### 2. 实现自己的第一个回合循环 (3 小时)

- [ ] 你：使用成熟 LeRobot 接口和约定的检查点执行设置实现循环，首版仅支持一个任务和一个回合。
- [ ] 用真实张量梳理一次迭代，包括实际传入分词器的指令，以及发送给环境的七维动作。
- [ ] 以明确步数上限运行一个开发回合，验证开始时已经重置策略状态和动作队列。

### 3. 增加证据并排查集成问题 (3 小时)

- [ ] 智能体：围绕你的循环接入视频和轨迹写入，保留原始观测、预测、执行动作及完成信息。
- [ ] 你：如果行为异常失败，检查动作解码、图像朝向、特征映射、状态构建和相对控制。
- [ ] 为试点任务保存三个开发回合，诚实分类观察到的结果，不假设此时一定已有成功视频。

### 4. 独立修改循环后再复核 (2 小时)

- [ ] 前一小时关闭智能体，为循环增加推理调用次数和已执行动作数的计数。
- [ ] 预测动作分块执行时两个计数为何不同，再用真实轨迹验证解释。
- [ ] 后一小时与智能体审查修改，在保留清晰数据流的前提下简化代码。

### 5. 解释回合并准备重置实验 (2 小时)

- [ ] 结合视频和轨迹，解释某条具体指令如何经过一次动作块预测转化为运动。
- [ ] 确认正常结束及真实开发故障后资源都能关闭，并保留有用的错误上下文。
- [ ] 列出第 3 周对照所需控制的仿真器状态、随机数状态和策略缓存。

## 证据与完成检查

- [ ] 你编写的外层循环能运行有界的真实回合，并保存可播放视频及可检查轨迹。
- [ ] 成功、超时和基础设施故障保持可区分，抓取失败不会被当成执行异常。
- [ ] 能够解释动作缓存，并指出预处理和解码发生的位置。

## 关闭智能体后解释

1. 使用队列动作与生成新动作块相比，计算过程有哪些变化？
2. 回合之间要重置哪些状态，保留策略队列可能导致什么？
3. 为什么张量形状正确，物理控制仍可能错误？

## 给编程智能体的建议请求

> 审查我编写的回合循环伪代码和实现，补充连接层或记录工具，并解释集成错误，不替代我的首次尝试。

## 进入下一周的条件

有界回合循环和轨迹记录可靠后再继续。可以继续研究任务失败，但应先解决尚未解释的接口错误。
