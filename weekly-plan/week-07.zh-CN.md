# 第 7 周：相机与物体布局鲁棒性

[English](week-07.en.md) | [简体中文](week-07.zh-CN.md)

[每周计划索引](README.zh-CN.md) | [实施计划](../doc/IMPLEMENTATION_PLAN.zh-CN.md)

**目标:** 建立隔离的 LIBERO-plus 评估面板，并理解每类扰动改变了什么。

**开始条件:** 基础语言开发流水线和指标可用，基础环境的依赖及资源已有记录。

时间预算：五次学习共十二小时主动投入，其中一小时关闭智能体独立完成；电脑运行时间另计。

## 准备与学习

- 阅读实施计划中的鲁棒性方案，以及固定版本 LIBERO-plus 的安装、任务映射和资源加载代码。
- 区分仅相机变化、物理布局变化和独立仿真后端引入的差异。
- 检查各环境如何解析包导入、配置和资源，避免安装分支后重定向基础环境。

## 分次任务

### 1. 明确后端隔离与比较规则 (2 小时)

- [ ] 智能体：使用受支持配置机制准备独立 LIBERO-plus 环境，固定依赖、代码和资源版本。
- [ ] 你：验证两个环境分别导入预期包，并解析到正确资源和初始状态文件。
- [ ] 写清哪些相机用例能共享物理状态，以及布局比较为何需要明确的变体状态。

### 2. 创建并检查变体清单 (3 小时)

- [ ] 智能体：提供类别/任务元数据，按实际任务套件名称解析运行 ID，不假设元数据 ID 就是索引。
- [ ] 你：检查有代表性的相机和布局用例，核实目标物体及目的位置。
- [ ] 按种子 42，为每任务每维度固定十个变体及明确状态/种子引用，不根据已观察成功率选择。

### 3. 验证无扰动参考与开发试验 (3 小时)

- [ ] 在鲁棒性后端中，使用固定的原任务定义和状态构建计划中的无扰动参考回合。
- [ ] 为两个扰动维度运行独立开发试验，这些试验用例不得进入最终留出面板。
- [ ] 比较相机图像、物理状态、观测映射、评分和控制设置，混合结果前先排查意外后端差异。

### 4. 独立诊断扰动后再复核 (2 小时)

- [ ] 前一小时关闭智能体，用状态、图像、动作和视频，将一个开发扰动与合适的无扰动参考比较。
- [ ] 提出影响行为的原因，并指出由后端或评分器造成的替代解释。
- [ ] 后一小时与智能体审查推理，并完成一次受控开发检查。

### 5. 审查最终鲁棒性面板 (2 小时)

- [ ] 验证冻结面板对每个策略包含八十个扰动用例和八十个参考用例，映射可找回且无重复。
- [ ] 确认配置分支后基础 LIBERO 开发仍能运行，结果标签保留后端标识。
- [ ] 准备完成覆盖和分维度汇总，不把开发试验当成完整 LIBERO-plus 基准。

## 证据与完成检查

- [ ] 基础与鲁棒性环境能够独立解析预期代码、配置及资源。
- [ ] 相机和布局试验具备有效观测与目标评分，后端差异能够解释。
- [ ] 最终变体和参考清单独立于性能冻结，没有用于调参。

## 关闭智能体后解释

1. 为什么布局扰动不天然等同于与无扰动状态完全匹配的对照？
2. 如果两个 Python 环境解析到同一个错误资源配置，会发生什么？
3. 为什么鲁棒性面板需要在自身后端内设置无扰动参考？

## 给编程智能体的建议请求

> 实现隔离的 LIBERO-plus 连接层和变体清单支持，验证资源/配置解析，并让我检查和解读开发扰动。

## 进入下一周的条件

两个后端均可靠、最终鲁棒性用例已固定，且你能够识别试验中的物理与视觉变化后，再继续。
